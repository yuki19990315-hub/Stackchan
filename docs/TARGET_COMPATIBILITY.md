# Sanny 追加対応機種 — 互換性仕様

## 方針
Sanny は独立した Stack-chan 風アプリではなく、非公式の追加ハードウェアターゲットとする。固定上流 v2.1.0、Moddable SDK 10.1.0、host API 2を基準とする。上流へのPR、別リポジトリへの転送、配布や公開リリースは行わない。既存Pocket-Worldを変更しない。
現時点で公式対応機種として認定されたわけではない。

## 変更範囲
- 本家の起動・設定・表情・アニメーション・MOD・通信処理は可能な限り無改変で利用する。
- 端末固有のLCD、タッチ、IMU、I2S、電源、メモリ、USB、ストレージのみハードウェア層へ隔離する。
- 円形液晶では操作領域を安全範囲に配置する。顔の造形と動きは維持する。
- 機能が未接続の場合は未対応として検出し、動作不能なメニューやMODを有効にしない。将来の拡張用APIは削除しない。
- モーターは現在無効。上流のNoneDriverを採用し、サーボ設定・拡張用の設計を残す。
- カメラは現在無効。所持するUSBカメラのUVC対応、接続経路、VBUS供給、RAMは未検証であり、USB-UART端子への直結で動作すると仮定しない。
- 頭部専用タッチ、外部LED、SD、Dock、RFIDなどは装備と互換性を確認できるまで対応済みと表示しない。

## 実装順序
1. 固定SDKのビルド環境、顔診断、全体ホスト起動の確立。
2. 全体ホストにボードprovider・円形UI・入力・電源を統合。
3. 共有I2Sの診断を実機で確認し、本家の音声APIへ接続。
4. 本家の会話MODと接続を移植。2MiB PSRAMで動作測定し、未対応経路を区別。
5. MOD・Webツール・BLEの互換性検証と安全な更新、長時間試験。
6. モーター、カメラは利用者が導入を希望した段階で別のオプションプロファイルを設計。

Grokなどの上流外サービス追加は本家互換性を確立した後の任意拡張とする。APIキー・Wi-Fi情報はコミットしない。マイクは利用者の明示操作で会話開始した場合のみ送信する。
