# 音声独立診断（実機・コンパイル未確認）
ESP-IDF 5.x向け。GPIO15/16/17/18は候補のみ。実際の端子・電源・スピーカー定格を確認後、`idf.py set-target esp32s3`、`idf.py -D SANNY_AUDIO_PINS_CONFIRMED=ON build`。診断用ファームウェアでありPocket-Worldを置き換えるため、バックアップ・復元方法が確定するまで書き込まない。16kHz、32-bit stereo Philips I2S、共有クロック、左マイク、低振幅テスト音、ピーク値と空きメモリをシリアル表示。音声保存・外部送信なし。通常のスタックチャンにはまだ接続していない。独立診断後、上流の音声API用の共有I2Sバックエンドを実装する。
